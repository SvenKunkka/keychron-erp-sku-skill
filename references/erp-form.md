# ERP 全新定制 SKU 表单参考

ERP URL、组织内部表格、负责人和状态名称应放在 `project-config.local.json`，不能写入公开仓库。

## 申请类型边界

| 类型 | 适用范围 |
|---|---|
| 全新定制 SKU | 产品规格形成全新组合，需要申请新的主 SKU；通常必须上传真实产品图片 |
| 尾缀 SKU | 已有主 SKU，仅增加客户、地区或渠道尾缀；本 Skill 不处理 |
| 条码/EAN 申请 | 为已有 SKU 申请条码；本 Skill 不处理 |

是否属于全新组合必须以当前 SKU/EAN 主表和 ERP 申请列表为准，不能根据型号名称猜测。

## 表单字段

当前脚本允许以下字段；实际必填项和选项以本地 ERP 当前页面为准。

| 字段 | 控件 | 填写原则 |
|---|---|---|
| SKU 编码 | 文本 | 是否可留空由当前内部流程决定 |
| 中文描述 | 文本 | 与精确型号、品类、颜色一致 |
| 英文描述 | 文本 | 与中文描述表达同一组合 |
| 类目 | 下拉 | 来自当前项目/配置资料 |
| 单位 | 下拉 | 使用 ERP 中实际选项 |
| 产品负责人 | 下拉 | 来自当前项目负责人记录 |
| 状态 | 下拉 | 使用本地流程规定的初始状态 |
| 品牌 | 下拉 | 来自精确型号资料 |
| 键帽/鼠标工艺 | 下拉 | 由类目和当前资料确定 |
| 系列 | 下拉 | 选择 ERP 中真实存在的系列选项 |
| 类型 | 下拉 | 使用当前流程定义 |
| 键帽颜色 | 文本 | 键盘或鼠标均按真实颜色填写 |
| 键数 | 数字 | 不适用时留空 |
| 特殊属性 | 下拉 | 例如内置电池；必须有资料依据 |
| 主控IC | 文本 | 来自精确型号电子规格书 |
| 键帽高度 | 下拉 | 不适用时留空 |
| 版本布局 | 下拉 | 来自目标 SKU/配置范围 |
| 销售标签 | 下拉 | 使用当前流程定义 |
| 库存严控 | 下拉 | 使用当前流程定义 |
| 轴体 | 文本域 | 填写真实轴体/开关；不适用时明确写不适用 |
| 备注 | 文本域 | 最多 130 字，只保留已核实关键规格 |
| 产品项目附件 | 上传 | 可选，按本次授权使用 |
| 上传图片 | 图片文件 | 全新 SKU 提交必须使用精确型号的真实图片 |

## 页面自动化约束

1. 备注超过约 130 字可能导致接口失败，脚本在启动浏览器前拦截。
2. 提交成功必须同时满足：提交请求为 2xx、可见弹窗关闭、列表回读出现配置的成功状态。
3. 下拉选择只点击文本完全相等的可见选项；找不到就停止。
4. Angular/React 表单必须通过原生 value setter 和 input/blur 事件写入，不能只改 DOM 属性。
5. 图片扩展名和文件签名都必须是受支持的真实图片格式。
6. 登录态、字段、上传、接口或回读异常时立即停止；提交结果不确定时禁止自动重试。
